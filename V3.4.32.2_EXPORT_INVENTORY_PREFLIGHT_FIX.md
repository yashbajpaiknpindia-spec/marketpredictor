# MarketPredictor v3.4.32.2 — Export inventory preflight hardening

## Fixes

- Fixed the Replay data-plan preflight NameError caused by `export_verified` / `export_unavailable` not being initialized before use.
- The preflight now calls the same `_collect_export_archive_inventory()` source of truth used by the stored-data inventory.
- Export inventory failures are fail-soft: Replay preflight remains usable, reports `export_inventory_error`, and leaves the authoritative Replay cache-first/missing-only worker check unchanged.
- The UI surfaces an export-inventory warning without converting the entire stored-data check into a failure.
- Added a regression test that asserts the export inventory variables are bound before any read.

## Trading/replay behavior

No strategy definitions, strategy count, entry logic, loss-stop logic, profit protection, or portfolio decision logic were changed by this patch.
