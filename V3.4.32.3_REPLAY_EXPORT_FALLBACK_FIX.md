# MarketPredictor v3.4.32.3 — Replay Export Fallback + Preflight Reliability

## Fixes

1. Auto replay no longer aborts merely because an older completed Export Data record is unavailable on the current worker. It reuses every accessible archive/cache first, then downloads only genuinely missing ticker-days. `stored_only` still refuses missing data.
2. Replay export hydrator now keeps the source interval per archive candidate, preventing a later archive from accidentally controlling 1m→5m resampling for an earlier candidate.
3. Export archive inventory is cached briefly to prevent repeated ZIP/DB accessibility scans while changing Replay dates; explicit Inventory refresh invalidates that cache.
4. Replay data-plan browser preflight timeout increased from 8s to 30s and raw `AbortError` / `signal is aborted without reason` is converted to a clear timeout message.
