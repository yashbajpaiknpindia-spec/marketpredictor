# MarketPredictor v3.4.31.6

## Fixes

### Extended Replay date boundary
Fixed a child/parent replay validation bug. Extended replay correctly permits historical windows up to `INTRADAY_REPLAY_EXTENDED_LOOKBACK_DAYS`, but its child segments were incorrectly routed through the normal replay validator capped by `INTRADAY_REPLAY_MAX_LOOKBACK_DAYS` (59 days by default). Child segments now opt into the extended lookback explicitly. This prevents valid older sessions in 30/60-day or 1-year segmented replays from failing with `No valid trading days selected`.

Normal single-run replay retains its existing 59-day safety boundary.

### Database diagnostics UI
The detailed Database Bootstrap diagnostics have been removed from the top of every page. The compact DB badge remains in the header, while the full diagnostic panel is now at the bottom of **Export Data** inside a collapsed Show/Hide section. The diagnostic endpoint and copy-report function remain available.

This is a UI-only placement change and does not alter database bootstrap behavior.

### Replay interval
Replay continues to use `INTRADAY_DATA_INTERVAL`. In this build the default is `1m`; it is not hardcoded to 5m. Stored 1m replay data can be resampled to 5m when the requested interval is 5m and 5m candles are missing.
