# MarketPredictor v3.4.6.1 — Replay Forensics Export Fix

## Issue fixed
The forensic replay download endpoint could fail with:

`TypeError: Object of type function is not JSON serializable`

The `strategies.json` export included live Python evaluator functions from the strategy definitions. The existing JSON fallback handled NumPy, Decimal and datetime values, but not callable objects.

## Fix
`_json_safe()` now converts:

- strategy functions/methods/builtins -> callable metadata (`module`, `qualname`)
- classes -> class metadata
- callable objects -> class metadata
- NumPy arrays/scalars
- Decimal
- datetime/date/time
- pathlib paths
- bytes/bytearray/memoryview
- dataclasses
- sets/tuples
- nested dicts
- pandas-like datetime/array values where supported

The exporter therefore preserves the identity of a strategy evaluator without attempting to serialize executable code.

## Expected result
`GET /api/intraday-replay/<run_id>/download?format=csv` should return the full forensic ZIP rather than HTTP 500.

The JSON download path uses the same safe serialization boundary.
