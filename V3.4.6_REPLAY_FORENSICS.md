# MarketPredictor v3.4.6 — Replay Forensics

## Export contract
Every new Intraday Replay download is a self-contained forensic ZIP. It includes:

- immutable run configuration and universe/date snapshot;
- every persisted trade and all strategy attribution fields;
- every replay event with full JSON detail and strategy/capital columns;
- per-tick capital/equity snapshots;
- all 20 strategy definitions, audit counts and observed performance;
- the run's cached stock candles;
- captured NIFTY/VIX/sector/daily reference inputs;
- SHA-256 manifest and row counts.

`INTRADAY_REPLAY_EVENT_LOG_LIMIT=0` is the default and means unlimited replay event persistence.
`INTRADAY_REPLAY_SNAPSHOT_EVERY_TICKS=1` records a capital snapshot every simulated tick.

The existing replay download endpoint remains compatible with `format=csv`, but that response is now the full forensic package rather than a partial export.
