# MarketPredictor v3.4.28 — AI Research Copilot + Approval-Gated Agent Mode

## Modes

- **Read**: analyzes live application context. No mutation.
- **Propose**: converts a natural-language request into a validated, reversible settings proposal.
- **Execute approved**: only an explicitly confirmed proposal can mutate the whitelisted application settings.

## Agent safety boundary

Agent Mode cannot:

- place live orders
- enable/disable trading
- switch trading execution mode
- change broker credentials
- change account capital
- delete database data
- mutate source code
- access or expose secrets

## Reversible changes

The current whitelist covers research/trading controls such as risk per trade, daily loss guard, position limits, confidence/RR gates, opening confirmation, profit-protection settings, trailing-stop settings, and scanner selection thresholds.

Every proposal stores:

- the original settings snapshot
- normalized proposed settings
- rollback snapshot
- rationale and user question
- status and timestamps
- apply/rollback audit events

Applying a proposal verifies that the current settings still match the proposal's original snapshot. A stale proposal is rejected instead of overwriting a newer manual change.

## Live trading isolation

The agent does not receive a live-order tool. Live execution remains behind the application's existing broker/trading controls and is not part of Agent Mode's mutation surface.
