# V3.2.2 Historical Export UI Status

The Historical Data export screen now exposes export completeness directly in the UI after a job completes.

It shows:
- Stocks with data / stocks requested
- Index/context series downloaded / requested
- Number of successful fallback acquisitions
- Number of missing or limited datasets
- Dataset-level status table with dataset, status, rows, source, and reason/note
- A Details button on completed historical exports to reopen the completeness report

Status examples include OK, FALLBACK_OK, DAILY_FALLBACK, PARTIAL, MISSING, FAILED, CREDENTIAL_MISSING, and NOT_AVAILABLE.

The ZIP remains the source of record through manifest.json, quality/dataset_status.csv, reference/fallback_provider_attempts.csv, and related quality files.
