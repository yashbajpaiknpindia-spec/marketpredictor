# MarketPredictor v3.3.1 — Database Visibility & Non-Blocking DB Recovery

- Web process binds independently of PostgreSQL.
- Added `/healthz` DB state fields: `db_status`, `db_error`, attempts and timestamps.
- Added `/api/system-status` DB-free status endpoint.
- Added a live database status light to the header: Connected / Connecting / Offline / Not configured.
- `/api/market-status` is explicitly DB-free and no longer blocked by the global database gate.
- PostgreSQL connections now use a bounded `connect_timeout` (default 8s).
- Failed DB initialization retries automatically in the background (default 10s).
- DB-dependent API calls return a short 503 with explicit database state instead of holding the browser request for 45s.
- Replay, the 20-strategy engine, trading/paper components and existing application structure are preserved.
