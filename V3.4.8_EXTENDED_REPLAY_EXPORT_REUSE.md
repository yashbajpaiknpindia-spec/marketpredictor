# MarketPredictor v3.4.8 — Extended Intraday Replay + Export Data Reuse

## Replay data-source priority
For every new Intraday Replay run, historical stock candles are resolved in this order:

1. Existing persistent Replay candle cache.
2. Completed **Export Data** ZIP archives that cover the needed interval/date/symbol.
3. Provider/network fetch only for ticker-days still missing after steps 1–2.

NIFTY and sector intraday reference files from completed Export Data archives are also seeded into the Replay reference cache before any provider request.

## Safe extended replay
The dedicated Intraday Replay page now offers:

- 30 days
- 60 days
- 1 year
- Custom extended date range

Extended windows are **segmented into bounded child replays** instead of loading the entire date range into one worker. Each segment completes safely, end-of-day positions are flattened as usual, and ending capital is carried into the next segment. The parent run exposes aggregate progress/results and the child run IDs.

## Strategy integrity
The 20 existing strategy definitions and strategy code are unchanged. Extended replay reuses the normal Replay engine; it does not replace, retune, reorder, or rewrite the strategies.

## UI
The Intraday Replay workspace now shows a short operational summary covering cache reuse, strategy integrity, forensic export, and safe segmentation. The long explanatory block is not needed to run a replay.
