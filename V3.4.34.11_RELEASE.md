# MarketPredictor v3.4.34.11

## Storage Steward + exact-session data audit

- Historical Export inventory now records/compares exact date scope, trading-session count, universe fingerprint and persisted chunk state.
- 1m and 5m archive scopes are compared without interval in the scope fingerprint, so 5m redundancy detection can correctly identify a matching 1m source.
- 5m archives may be flagged only when a persisted matching 1m archive or complete canonical 1m coverage proves the stock series is reconstructible; extra index/sector/context files remain a manual review item.
- Metadata-only / missing-chunk archives are surfaced explicitly and are not silently recreated or deleted.
- Storage Steward scans are read-only and are no longer run every 30 seconds; deep audits run only on demand and after an explicit delete/cleanup refresh.
- Market Data exact-session presets remain compact and storage estimates are shown before acquisition.
- Render free PostgreSQL quota is explicit in the blueprint (1 GiB) while still allowing a configured override.
- The DB schema version remains `3.4.34.10-large-data-memory-safety` so this release does not trigger another production-wide schema migration merely for UI/audit improvements.
