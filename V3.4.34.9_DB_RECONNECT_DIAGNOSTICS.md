# MarketPredictor v3.4.34.9 — DB reconnect diagnostics

Fixes deployment situations where the application shell is available but the header shows DB Offline and Storage APIs fail.

- Resolves DATABASE_URL lazily at runtime and supports compatible Render aliases.
- Exposes the DB environment source and bootstrap signal in `/api/db-status`.
- Adds `POST /api/db-reconnect`, a non-destructive recovery endpoint that retires a stale pool and restarts the bootstrap supervisor.
- Storage page now displays the actual DB state/error and has a `Reconnect DB` button.
- No data deletion, schema reset, or destructive recovery is performed.
- Existing storage/research/data protections remain unchanged.
