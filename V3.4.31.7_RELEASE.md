# MarketPredictor v3.4.31.7 — Unlimited Historical Lookback + Long-Range Export

## What changed

- Removed the Historical Export application's default 150-day lookback restriction.
- Removed the default 130-calendar-day per-export range restriction.
- `HISTORICAL_EXPORT_MAX_LOOKBACK_DAYS=0` now means unlimited lookback; a positive value remains available as an operator guard.
- `HISTORICAL_EXPORT_MAX_SPAN_DAYS=0` now means unlimited range; a positive value remains available as an operator guard.
- Raised the default per-export row safety ceiling to 100,000,000. Memory and disk safety checks remain active, and Preview Size still reports the expected row count/API workload.
- Added one-click Historical Export presets for 1 year, 2 years, 3 years, 5 years and 10 years, while retaining Custom date selection.
- Long ranges continue to use provider-safe bounded historical API windows rather than submitting multi-year provider requests.
- Very old/unsupported intraday history is recorded as missing/limited data instead of being blocked by the application solely because it is older than 150 days.

## Important data-availability note

Removing the application lookback ceiling does not create historical candles that the upstream provider does not serve. The export records unresolved or incomplete series in its quality/completeness artifacts. Full 1-minute multi-year universes can be extremely large; use Preview Size and the disk/memory safety checks before starting.
