# MarketPredictor v3.4.34.1 — Evidence Report Download

## Changes
- Added downloadable Evidence Report controls to Strategy Evidence & Decision Audit.
- `GET /api/evidence/report?format=html` downloads a human-readable HTML report.
- `GET /api/evidence/report?format=zip` downloads a forensic ZIP containing report.html, snapshot.json, strategy evidence, decision-audit summary/trades CSV, and JSON source data.
- Snapshot-specific downloads accept `snapshot_id`.
- Added `side` migration to `intraday_replay_trades` so Decision Audit can read legacy databases safely.
- Bumped DB schema/evidence registry versions for the new migration/report contract.

## Evidence safety
The report is read-only. It does not modify strategy definitions, backfill future information, or promote evidence. Expectations remain frozen at decision time and actuals are calculated from recorded completed trades.
