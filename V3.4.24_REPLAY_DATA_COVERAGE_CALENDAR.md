# MarketPredictor v3.4.24 — Replay Data Coverage Calendar

## What changed
- Added a compact date-level Stored Candle Coverage calendar beside Replay's date controls.
- Green dates mean the complete Replay universe is already in the persistent Replay candle cache and can be reused without provider download.
- Light-green dates mean a completed local Export Data archive covers the date/range; Replay hydrates locally before considering a provider request.
- Amber means partial ticker-day coverage; grey means no stored coverage in the replay cache/export sources.
- Candle resolution is shown on each date (`1m`, `5m`, or `1m→5m`).
- The calendar refreshes when the requested date range changes and after a replay completes.
- Data preflight is now network-free and uses one indexed grouped coverage query instead of a full ticker/day count scan.
- A 5-minute replay can derive missing 5-minute cache days locally from a fully cached 1-minute replay day, avoiding a second provider download.
- Added an index on `(market, interval, trading_date, ticker)` to accelerate coverage checks.

## Reuse contract
The replay worker remains authoritative. It loads exact cached days first, hydrates missing days from persisted Export Data when available, and sends only still-missing ticker-days to the provider. The new preflight never downloads data and does not replace the worker's final missing-day check.
