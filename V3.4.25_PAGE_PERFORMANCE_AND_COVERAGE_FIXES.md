# MarketPredictor v3.4.25 — Page Performance, Strategy Evidence, and Coverage Inventory

## Changes
- Strategy Dashboard moved to its own first-class page; Intraday Engine no longer loads the strategy dashboard on every engine visit.
- Trade History fast path now reads the persisted ledger without forcing open-position exit reconciliation. Exit reconciliation is explicit via a separate button.
- Export manifest has a lightweight metadata path (`summary=0`) and optional summary statistics loaded in the background (`summary=1`).
- Replay stored-candle calendar keeps the existing compact design: Replay cache = green, Export Data = light green, Partial = amber, Not stored = grey. The calendar now renders every month in the stored inventory as horizontally scrollable month cards and keeps 1m/5m/1m→5m resolution markers.
- Replay coverage inventory is briefly cached server-side to make repeated date navigation fast.
- Failure-pattern panel now supports drill-downs for all analyzed trades by strategy, all losing trades by failure type, and all winning trades by recorded exit mechanism. The drill-down uses the same denominator as the headline replay sample.
- Conservative attribution remains unchanged; unattributed rows are explicitly identified rather than assigned to a strategy by guesswork.
