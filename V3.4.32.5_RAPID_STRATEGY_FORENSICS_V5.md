# MarketPredictor v3.4.32.5 — Rapid Strategy Forensics v5

Base build: `v3.4.32.5-replay-memory-relaxed-fixed`

## v5 fixes

- Rapid Scan terminal state is now restart-safe even when the final PostgreSQL write is interrupted. A durable checkpoint can self-finalize a run once all requested sessions were completed.
- Rapid Scan ZIP export no longer fails for legitimate zero-signal runs. Zero-signal results still export strategy/audit/session/config/data-quality artifacts.
- Rapid strategy evaluator exceptions are no longer silently discarded. Each strategy reports an evaluator-error count and the UI distinguishes evaluator failure from insufficient evidence/zero signals.
- If the fast hard-condition gate fails parity sampling, Rapid Scan automatically falls back to evaluating all strategy functions on the affected ticker-day rather than silently dropping eligible signals.
- Rapid Scan checkpoint rows now include live strategy/session/stock summaries so a running scan can expose useful evidence before final completion.
- Rapid Scan polling no longer rebuilds the large result tables on every 1.5-second status tick. Detailed result tables refresh only when the checkpoint/result signature changes, preventing scroll jitter and the appearance of page reloads while users scroll.
- The Rapid Scan `View` action no longer forces the browser back to the top of the page.
- Historical 1-minute export/download jobs now show a true percentage progress bar based on provider windows, alongside stage, chunk counts, elapsed time, rows and stocks.
