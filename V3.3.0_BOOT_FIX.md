# MarketPredictor v3.3.0 — Render/Gunicorn boot fix

## Root cause found in v3.2.9
Python's `threading.Timer` constructor does not accept `daemon=True` as a keyword argument. v3.2.9 used:

```python
threading.Timer(delay, callback, daemon=True)
```

That raises:

```text
TypeError: Timer.__init__() got an unexpected keyword argument 'daemon'
```

The exception occurred while importing `app:app`, so Gunicorn could not boot its worker.

## Fix
Timers are now created first and then marked daemon explicitly:

```python
timer = threading.Timer(delay, callback)
timer.daemon = True
timer.start()
```

This was fixed in both the initial 30-second server autostart timer and the 15-second database-readiness retry timer.
