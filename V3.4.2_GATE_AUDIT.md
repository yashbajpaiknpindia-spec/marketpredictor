# MarketPredictor v3.4.2 — Signal Gate Audit

## Global signal gates in Replay RAW mode

These no longer modify strategy eligibility in RAW 20-strategy mode:

- global VWAP requirement (`require_vwap`)
- global opening-breakout requirement (`require_opening_breakout`)
- dynamic pre-scan shortlist
- global price-focus filter
- strict-learning trade-history blocks/score changes
- evidence / expected-net-edge gate
- flat global minimum score
- global disabled-strategy list
- prior exit calibration in RAW baseline

## Strategy-native VWAP usage

The strategy catalogue itself is unchanged. A strategy that explicitly references VWAP keeps that rule. A strategy that does not reference VWAP is not forced through a global VWAP gate.

## Common execution layer

Raw mode still uses a common downstream execution/risk/cost layer so the comparison is honest about fills and costs. Any rejection there is reported separately from strategy eligibility.

## 20-strategy audit

Every scan cycle evaluates LONG and SHORT for each registered strategy. Replay aggregates `evaluated`, `eligible`, and `selected` counts so we can verify that strategies actually ran.
