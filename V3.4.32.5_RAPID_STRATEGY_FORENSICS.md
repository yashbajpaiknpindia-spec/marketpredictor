# MarketPredictor v3.4.32.5 — Rapid Strategy Forensics

Adds a standalone **Rapid Scan** page for fast 1-minute strategy screening.

## Contract
- Uses the existing 20 strategy definitions unchanged.
- Uses stored/replay-cached 1-minute stock candles; missing ticker-days are reported instead of silently downloading a large stock dataset.
- Calculates shared features once and applies necessary-condition gates before invoking individual strategy functions.
- Measures MFE/MAE and chronological first-event ordering for the configured loss ceiling and profit activation thresholds.
- Default diagnostic thresholds: -0.125% loss ceiling and +0.40% profit activation.
- These thresholds are diagnostics in Rapid Scan, not a substitute for full Replay execution logic.
- Full Replay and the ₹2,00,000 portfolio simulation remain the final validation stages.

## Render safety
- One Rapid Scan worker is allowed per process.
- Processing is bounded by trading-week batches and small DB cache reads.
- No per-signal DB inserts are performed.
- PostgreSQL stores only compact run summaries and bounded forensic samples.
- ZIP export contains summary JSON/CSV, weekly checkpoints, forensic samples, and methodology notes.

## Validation
- Inline browser JavaScript passes `node --check`.
- Python modules pass `py_compile`.
- Smoke test against a real cached 1-minute NSE file matched the frozen strategy engine gate exactly: 0 missed eligible signals and 0 evaluator mismatches in the sampled parity check.
