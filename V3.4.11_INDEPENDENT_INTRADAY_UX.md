# MarketPredictor v3.4.11 — Independent Intraday + Focused UX

## Intraday execution
- Live/paper Intraday Engine is permanently independent across the 20 existing strategies.
- No cross-strategy winner selector is used for normal intraday execution.
- Centralized capital, position, cost, and exit controls remain the shared safety layer.
- Existing strategy definitions and rules are unchanged.
- Intraday order persistence defaults to independent attribution when a plan lacks an explicit mode.

## Capital
- Canonical Indian paper/replay capital default: ₹200,000.
- Known legacy ₹5,000 factory rows are upgraded once at DB initialization; deliberate non-default capital is left untouched.

## UI / UX
- Intraday Engine opens as the default workspace.
- Research Lab and Trading Automation are hidden from the primary tab bar and available from `⋯ More`.
- Intraday page shows a clear independent-strategy banner.
- Replay result screen no longer exposes a separate Capital & P&L breakdown button; the focused results dashboard already includes starting capital, ending capital, net P&L, capital return and day-by-day results.
- Replay stage messaging explicitly says Independent 20-strategy execution / selector OFF.

## Replay result correctness
- Presentation-only daily capital breakdown for older replay runs now uses a fresh DB connection after the main status query; this fixes historical rows that previously fell back to the misleading sum of individual trade-return percentages.
