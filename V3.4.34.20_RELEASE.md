# MarketPredictor v3.4.34.20

## Parallel Rapid upgrade + durable restart continuity

- Live legacy sequential Rapid roots are upgraded in place after deployment/restart instead of silently continuing serially.
- The existing logical run ID and completed-session aggregates are preserved.
- An in-progress legacy session keeps its `active_day_state` / batch cursor and resumes from the last durable 25-ticker checkpoint.
- Remaining sessions become durable child shards and execute behind memory-capped concurrent lanes.
- Parent parallel coordinator now restores its own checkpoint on restart; completed evidence cannot disappear after a web-service restart.
- Status always exposes parallel summary/lanes for a parallel parent, even while child telemetry is temporarily empty.
- Live status builds a lightweight result from the durable parent checkpoint so technical analysis, session P/L, and stock exposure populate during a running scan instead of waiting for terminal completion.
- ETA after a serial-to-parallel upgrade is measured from the parallel migration/start point rather than the old serial runtime.
- Parallel wave remains a scheduler batch (10/12/20/30 sessions); only Auto/1-4 bounded worker lanes run concurrently to protect the 512 MB service.
- Existing verified ticker-days and per-25-ticker checkpoints remain restart-safe; completed work is not redownloaded or needlessly rescanned.
