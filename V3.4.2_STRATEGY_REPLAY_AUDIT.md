# MarketPredictor v3.4.2 — Strategy Replay Audit

## Purpose

This release makes Intraday Replay the controlled research path for the 20-strategy catalogue. The old Intraday Backtest Lab remains removed.

## Signal modes

### RAW 20-strategy

The Replay baseline evaluates the 20 strategy modules using their own deterministic rules. The following global signal gates are disabled for RAW mode:

- global VWAP gate
- global opening-breakout gate
- dynamic pre-scan shortlist
- global price-focus filter
- strict-learning blocks/score adjustments
- evidence/expected-value gate
- flat global minimum-score gate
- global disabled-strategy list
- unvalidated/previous exit calibration

Common execution/risk/cost mechanics remain downstream and are shown separately as execution rejects; they do not alter strategy eligibility.

### Live parity

Live-parity replay keeps the current learning and global signal gates for a direct “what would Live have done?” simulation.

## Replay stages

The UI/API now reports:

1. `loading_data`
2. `strategy_evaluation`
3. `execution`
4. `finalizing`
5. `completed` / `stopped` / `error`

The status payload also reports cumulative strategy evaluations, eligible signals, selected signals, symbols with data, and execution rejects.

## Strategy audit

Every replay tick evaluates both LONG and SHORT for every registered strategy when the strategy engine runs. The run aggregates per-strategy `evaluated`, `eligible`, and `selected` counts across the full pre-scan pool.

## VWAP gate finding

The Replay UI no longer exposes “VWAP confirmation” as a run-level strategy override. In RAW mode, a global VWAP requirement cannot rewrite the strategy catalogue. Strategies that explicitly use VWAP do so inside their own rule definitions; strategies that do not use VWAP are not globally forced to satisfy it.

## Runtime fixes

The release also restores the replay candidate snapshot/scoring/price-filter helpers that were missing from the deployed application and caused `fetch_intraday_candidate_snapshot` `NameError` failures.

Bank sector context now reuses the known `^NSEBANK` alias instead of the unsupported `^NIFTYBANKIDX` alias.
