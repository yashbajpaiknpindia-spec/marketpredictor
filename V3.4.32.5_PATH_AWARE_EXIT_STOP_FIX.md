# MarketPredictor v3.4.32.5 — Path-Aware Exits + Rapid Stop Fix

## What changed

### Historical Replay exits are now path-aware

Replay no longer waits for a 1-minute candle to close before applying newly armed profit protection. Each OHLC bar is replayed through a documented deterministic intrabar path:

- bullish candle: `Open → Low → High → Close`
- bearish candle: `Open → High → Low → Close`
- doji: prior close is used as the direction tie-breaker

This allows a trade that reaches the configured profit-protection activation inside a candle to arm its protection and react to a reversal later in that same candle.

Protection uses a true net break-even floor where the round-trip cost model makes that floor reachable. The original strategy stop remains the original stop; the protection layer only raises/lowers the protective exit after activation.

Path diagnostics are persisted on replay trade records (`path_aware`, `path_model`, `path_activation_seen`, `path_exit_step`, `path_exit_point`, `path_exit_fill_price`).

### Rapid Scan stop behavior

Rapid Scan stop is now cooperative and restart-safe:

- the worker checks the stop event/database flag during ticker-day work;
- a partially processed session is discarded rather than checkpointed as complete;
- the UI stops rebuilding the result table while the worker is finishing its bounded operation;
- `stopping` runs are finalized from the durable checkpoint when the worker disappears after a restart;
- the worker-start race no longer changes a persisted stop request back to `running`.

### Synthetic forensic stability

The synthetic generator now bounds market, sector, and stock log paths/returns to avoid pathological thousands-of-percent MFE/MAE tails that were not representative of the intended intraday stress model.
