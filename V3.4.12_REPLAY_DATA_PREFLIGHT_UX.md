# V3.4.12 — Replay data preflight + progress UX

- Replay UI now links date selection and data-source selection in one workspace.
- Default policy is Replay DB cache → persisted Export Data → provider only for missing ticker-days.
- Added Stored-data-only mode that never calls a provider and stops cleanly when required data is missing.
- Added `/api/intraday-replay/data-plan` preflight; it performs no market download.
- Added visible run status/progress for historical-data loading, including replay ID and data-stage detail.
- Long replay windows (30/60/1y) automatically route through the bounded segmented worker.
- Increased default persisted historical-export archive retention from 1 to 5 DB archives so completed Export Data artifacts remain reusable across more future replays.
- Existing 20 strategy definitions are unchanged.
