# MarketPredictor v3.4.29 — UI/UX refresh + shared stored-data inventory calendar

## UI/UX

- Refreshes the product shell with a more compact finance-terminal feel: clearer typography, tighter spacing, consistent control heights, improved focus states, calmer cards, and stronger active navigation states.
- Keeps the existing light/dark theme behavior and application routes intact.
- Improves Replay/Data/AI Copilot presentation without changing trading or replay calculations.

## Stored-data calendar source of truth

- The persistent `/api/data-inventory/coverage` inventory is now the calendar source of truth for both **Export Data** and **Intraday Replay**.
- Intraday Replay loads the persistent inventory independently of the current Replay date window.
- Replay overlays the selected Replay sessions on the same stored-data calendar instead of maintaining a separate calendar implementation.
- Export Data uses the same calendar rendering function, so the month/day states and legends remain synchronized.
- Existing Replay cache / 1m→5m / Export Data / partial / holiday states are preserved.

## Replay inventory controls

- Replay now includes month navigation and a compact stored-range summary.
- Selected Replay dates are outlined without changing the underlying persistent inventory.
- Refreshing Replay coverage reuses the existing cache-first authoritative replay preflight; the persistent calendar itself never downloads market data.

## Refresh behavior

- The Replay and Export Data inventory refresh controls can request `refresh=1` to invalidate the server-side inventory TTL and immediately rebuild the stored-data view from persisted cache/export metadata.
- This refresh does not download market data; it only refreshes the inventory view.
