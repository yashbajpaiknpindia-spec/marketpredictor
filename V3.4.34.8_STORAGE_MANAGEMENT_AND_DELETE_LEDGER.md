# MarketPredictor v3.4.34.8 — Storage Management, Exact Cleanup Review, and Delete Ledger

## What changed
- Replaced the repeated Storage navigation links with one inline SVG database icon.
- Added a deeper Database & Storage console with exact table ownership, protection labels, row estimates, table/index sizes, and configured quota usage.
- Added exact cleanup previews before destructive operations.
- Bulk cleanup now accepts the exact candidate IDs returned by the preview instead of silently re-querying a broad age range.
- Added persistent `storage_cleanup_log` to PostgreSQL so the application can report what was actually deleted, when, from which category, and the post-delete integrity result.
- Added individual Replay deletion controls from Storage.
- Added individual Historical Export job deletion, removing its DB metadata and PostgreSQL archive chunks plus local files where present.
- Added archive SHA-256 recording for newly persisted Historical Export archives and duplicate/same-request review based on range, interval, universe parameters, size, and hash.
- Older persisted archives without a recorded SHA-256 are explicitly labelled unverified rather than assumed duplicate.
- Canonical 1-minute market data remains protected from these bulk cleanup cards.

## Safety rules
- No database recreation, table truncation, or destructive schema reset.
- Active/pending/running/stopping Replay and acquisition jobs are protected from age cleanup.
- Live/paper execution records and strategy memory remain protected.
- Cleanup runs a post-delete integrity audit and records the result.
