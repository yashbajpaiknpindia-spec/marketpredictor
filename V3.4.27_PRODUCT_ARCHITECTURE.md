# MarketPredictor v3.4.27 — Product Architecture / Fresh-DB / Copilot / Navigation

## Fresh database recovery
- Replay candle cache is created before its coverage index.
- A runtime self-heal recreates `intraday_replay_candle_cache` and its index if a fresh/reset database is missing them.
- `ai_copilot_events` is also created idempotently.
- Historical Export keeps its own PostgreSQL metadata layer and local archive metadata files.

## Navigation
- Primary navigation now focuses on Scanner-independent workflows: Intraday Engine, Intraday Replay, Strategy Dashboard, Trade History, Export Data, and AI Copilot.
- AI Scanner, Track Record, API Costs, Research Lab and Trading Automation remain fully implemented but are hidden behind the eye/Hidden Pages menu.
- Hiding is UI-only; no route, view or API was removed.

## Risk defaults
- Default account risk per trade: 0.25% (₹500 at ₹2,00,000 capital).
- Default daily loss guard: 1.25%.
- Strategy price stops remain separate from account-risk sizing.

## Research Copilot
The in-app Copilot is read-only. It can inspect application-generated replay context and ask the configured OpenAI Responses API model questions about research evidence. It cannot place orders or change settings.

Environment variables:
- `OPENAI_API_KEY` — required to enable the Copilot.
- `OPENAI_COPILOT_MODEL` — default `gpt-5.6-luna`.
- `OPENAI_COPILOT_MAX_OUTPUT_TOKENS` — default 1200.
- `OPENAI_COPILOT_ENABLED` — set false to disable.

The current model selection follows the OpenAI API model catalog used for this build.
