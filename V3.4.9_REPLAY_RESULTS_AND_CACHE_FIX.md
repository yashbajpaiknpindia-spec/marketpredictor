# MarketPredictor v3.4.9 — Replay Results Dashboard + Strict Historical Data Reuse

## Replay / UX
- Replay results now open in a focused results view instead of leaving the user inside the setup/research controls.
- Saved replay dates are displayed as human-readable ranges, e.g. `5 Sep 2026 → 10 Sep 2026 · 5 sessions`.
- Results show starting capital, ending capital, net P&L, capital return, trade count, win rate and profit factor at the top.
- Day-by-day starting capital, P&L, daily return and ending capital are shown in a compact table.
- The old sum of per-trade percentage returns is no longer presented as account return; `capital_return_pct` is now the UI headline metric.
- Older replay rows are backfilled at read time for capital-return and day-by-day display without modifying historical results.

## Historical data reuse
- Normal RAW/LIVE replay now hydrates from completed Historical Export ZIPs before any provider request, matching Independent Tournament behavior.
- Persistent Replay candle cache remains the first source.
- Existing completed Export Data is the second source.
- Network/provider history is used only for genuinely missing ticker-days.
- Previously downloaded 1-minute Export Data can be reused and locally resampled to 5-minute Replay candles.
- Reference inputs continue to prefer persisted Replay/reference cache and completed Export Data before provider fetches.

## Extended replay
- 30-day / 60-day / 1-year segmented replay remains bounded-memory and carries capital between child segments.
- Extended results now retain day-by-day breakdowns from child runs.

## Strategy integrity
- The 20 strategy definitions and their rules are unchanged.
