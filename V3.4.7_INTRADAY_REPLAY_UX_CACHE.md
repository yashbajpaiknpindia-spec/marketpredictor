# MarketPredictor v3.4.7 — Intraday Replay UX + Cache Reuse

## What changed
- Added a dedicated **Intraday Replay** top-level page; Replay is no longer embedded inside Research Lab.
- Replaced the long Replay explanatory paragraphs with short, actionable summaries.
- Added visible replay summary cards for cache-first historical data, unchanged 20-strategy set, full forensic export, and capital tracking.
- Added live cache-status text showing cached ticker-days reused, new ticker-days downloaded, cache hit rate, and reference datasets reused/fetched.
- Added strict **missing-days-only** stock-candle fetching: a trading day already present in `intraday_replay_candle_cache` is never intentionally included in a new historical API request.
- Added cross-run reuse of persisted NIFTY/VIX/sector/daily replay reference inputs when the prior cached range fully covers the requested range.
- Kept the existing 20 strategy definitions and tournament code unchanged.

## Deployment note
The full application keeps files at repository root (`requirements.txt`, `render.yaml`, `.python-version`, `app.py`, etc.) so Render can build directly from the repository root.
