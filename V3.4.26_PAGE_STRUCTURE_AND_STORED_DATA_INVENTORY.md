# MarketPredictor v3.4.26 — Page Structure + Independent Stored Data Inventory

## Fixes

- Fixed a DOM hierarchy regression from v3.4.25 that left Strategy Dashboard, Trade History, and Export Data nested inside the hidden Intraday Replay container. All three are now direct children of the main workspace and load independently.
- Added an independent Stored Market Data Inventory under Export Data. It is not driven by the Replay start/end selection.
- Inventory calendar retains the stored-data visual contract:
  - dark green: Replay cache / instant reuse
  - light green: persisted Export Data / local reuse
  - amber: partial cache coverage
  - pink: exchange holiday
  - grey: no stored data / weekend
- Inventory supports 1-minute and 5-minute views. A complete 1-minute cache can be shown as locally derivable 5-minute coverage.
- Added earliest stored date, latest complete trading-data date, month count, complete/partial day counts, and month jump/earlier/later controls.
- Inventory is cached briefly server-side to keep navigation fast and never downloads market data.
