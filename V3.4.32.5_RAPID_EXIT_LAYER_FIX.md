# v3.4.32.5 — Rapid Path-Aware Exit Layer Fix

## Problem
Rapid Scan previously performed natural-price-path diagnostics only. It did not execute an exit-management layer per signal, so a Rapid run could report +0.40% reached / profit-then-loss behavior without actually simulating the path-aware protection decision.

## Fix
Rapid Scan now runs a lightweight path-aware execution shadow for every independent signal using:
- next-1-minute entry with the configured entry slippage;
- each strategy's own target and stop;
- configured profit-protection activation (default +0.40%);
- a 30% peak-profit giveback trail;
- a net break-even friction floor using the Rapid cost contract;
- the same deterministic historical OHLC path convention as Replay: O→L→H→C for bullish candles and O→H→L→C for bearish candles (prior-close direction for doji candles);
- the historical force-exit-before-close window;
- threshold fills at the touched target/stop/trailing level rather than a later candle close.

Natural EOD path metrics remain separate from path-aware exit metrics. This prevents the scanner from confusing "price eventually did X" with "the exit layer would have captured X".

## Validation
- 3 real historical sessions from the stored 1-minute archive were tested locally using RELIANCE.
- 200 independent strategy signals were generated.
- 200/200 received an exit-layer simulation.
- Trailing protection fired for active strategies.
- Exact production `resolve_path_aware_replay_bar_exit()` smoke test on real 1-minute candles: 8 positions, 6 trailing-protection exits, 2 horizon exits, 0 errors.
- Selected regression/static tests: 14 passed.

## Scope
This is Rapid Scan's fast execution shadow, not the final ₹2,00,000 portfolio simulation. Full Intraday Replay remains the production execution verifier and uses the full path-aware exit resolver.
